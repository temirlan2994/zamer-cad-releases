# Zamer CAD logo

Approved artwork imported from the [Google Drive logo folder](https://drive.google.com/drive/folders/11lz-910awcqZFyxR3eV6ebc779aa9-Dn).

The folded yellow ruler forms the letter Z. Preserve the artwork's colors, proportions, and orientation. The wordmark text is outlined, so no external font is required.

- `svg/zamer-cad-logo.svg`: wordmark for light backgrounds.
- `svg/zamer-cad-logo-dark.svg`: wordmark for dark backgrounds.
- `svg/zamer-cad-icon-small.svg`: simplified favicon for sizes up to 48 px.
- `png/`: original web icons; the square 512 px icon is also the legacy Android fallback.
- `png/android/`: 432 px layers for the adaptive Android launcher icon, including the Android 13 monochrome layer.

Run `npm run icons` from `prototype/` to copy these originals into the web and Android resource folders. This command preserves the original bytes; it does not recreate the old logo.
