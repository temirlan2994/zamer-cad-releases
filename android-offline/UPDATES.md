# Удалённые обновления через GitHub Releases

В версии 0.1.2 (versionCode 3) добавлен нативный обновлятор.
Это установочная версия для перехода: 0.1.0 и 0.1.1 не умеют обновляться сами,
поэтому 0.1.2 нужно один раз поставить вручную поверх старой APK.

## Текущее состояние

Обновлятор и сценарий сборки/публикации подготовлены локально.
Создан публичный репозиторий `temirlan2994/zamer-cad-releases`; аккаунт GitHub подключён.
Релиз 0.1.2 сохранён как draft: загрузка вложений ожидает разрешения локальных файлов
в расширении ChatGPT для Chrome. APK и update.json готовы в `dist/releases/0.1.2`.
Поэтому проверка реального релиза, скачивание и установка на телефоне ещё не проверены.
В APK уже встроен репозиторий `temirlan2994/zamer-cad-releases`.
Пока релиз не опубликован, ручная проверка сообщает, что релиз не найден.

## Подключение телефона

1. Установите `dist/Zamer-CAD-0.1.2-release.apk` поверх текущей версии, не удаляя приложение.
2. Используется публичный GitHub-репозиторий `temirlan2994/zamer-cad-releases`.
   Исходники и ключ подписи не публикуются.
3. В приложении откройте список проектов → круговые стрелки рядом с кнопкой «+».
4. Репозиторий уже настроен. При необходимости его можно изменить через «Настроить».
5. Оставьте «Проверять при запуске», если нужны автоматические проверки.
   Они выполняются при запуске приложения не чаще одного раза в 6 часов.
   Кнопка «Проверить» выполняет проверку сразу. В фоне после закрытия приложения проверок нет.
6. Когда доступна новая версия, подтвердите «Скачать».
7. Если Android запросит, разрешите «Установку из этого источника» для Zamer CAD,
   вернитесь в приложение, затем подтвердите установку в системном окне.

Установка всегда требует участия пользователя. Отказ, отмена и отсутствие интернета
не мешают работе с чертежами. Данные проекта не отправляются на GitHub.
Сетевые запросы раскрывают GitHub обычные данные соединения (например IP и User-Agent).

## Публикация с компьютера

Подпись выполняется на этом компьютере прежним ключом из
`%USERPROFILE%\.zamer-cad\signing`. Загружать ключ в GitHub Secrets не требуется.

Установите [GitHub CLI](https://cli.github.com/) и выполните `gh auth login`.
Вход через GitHub-плагин Codex и вход GitHub CLI — отдельные подключения.
Не вставляйте токены в исходники или сообщения чата.

Подготовка первой публикации (из корня проекта):

```powershell
.\android-offline\Publish-Release.ps1 -Repository 'temirlan2994/zamer-cad-releases'
```

Без `-Publish` сценарий только собирает, проверяет подпись и lint и готовит
`dist/releases/0.1.2/`: APK, SHA-256, `update.json`, описание релиза.
В APK встраивается выбранный репозиторий; его можно переопределить в настройках телефона.

Создать публичный репозиторий и опубликовать подготовленную версию:

```powershell
.\android-offline\Publish-Release.ps1 -Repository 'temirlan2994/zamer-cad-releases' -Publish -CreateRepository
```

Если репозиторий уже существует, уберите `-CreateRepository`.
Сценарий не отправляет исходники, конфигурацию подписи или локальные проекты.
Сначала создаётся draft с вложениями; затем релиз публикуется и помечается Latest.
Существующий тег не перезаписывается. При сбое загрузки проверьте draft на GitHub.

Для следующих обновлений увеличивайте **оба** значения в `app/build.gradle`:

```groovy
versionCode 4
versionName "0.1.3"
```

Затем запустите тот же сценарий с `-Publish`, при необходимости передайте описание:

```powershell
.\android-offline\Publish-Release.ps1 -Repository 'temirlan2994/zamer-cad-releases' -Notes 'Описание изменений' -Publish
```

Публикация описана в [GitHub CLI](https://cli.github.com/manual/gh_release_create),
формат метаданных релиза — в [GitHub REST API](https://docs.github.com/en/rest/releases/releases).

## Формат update.json

```json
{
  "packageName": "com.zamercad.offline",
  "versionCode": 4,
  "versionName": "0.1.3",
  "minSdk": 29,
  "apkUrl": "https://github.com/temirlan2994/zamer-cad-releases/releases/download/v0.1.3/Zamer-CAD-0.1.3-release.apk",
  "sha256": "64 шестнадцатеричных символа SHA-256 APK",
  "notes": "Описание изменений"
}
```

JSON должен находиться во вложениях **последнего опубликованного стабильного релиза**
под именем `update.json`. Draft и prerelease в проверку не входят.
В публичном репозитории загрузка доступна без токена на телефоне.
SHA-256 не является подписью: окончательное подтверждение подлинности APK выполняет
системный установщик Android. Подмена файла с другим ключом не даст обновить приложение.

## Защита и ограничения

- Только HTTPS с обычной проверкой TLS; перенаправления разрешены только на GitHub/CDN GitHub.
- Ссылки манифеста и APK должны принадлежать выбранному репозиторию.
- Проверяются SHA-256, имя пакета, увеличение versionCode, сертификат прежней версии,
  отсутствие debug-флага и совместимость Android.
- JSON ограничен 1 МБ, APK — 128 МБ; есть сетевые тайм-ауты и отмена скачивания.
- Скачанный APK лежит в закрытом кэше. ContentProvider отдаёт установщику только APK
  с именем SHA-256, только для чтения, по временному разрешению URI.
- Интернет разрешён нативному обновлятору. Удалённые страницы и ресурсы блокируются
  в WebView; интерфейс и чертежи продолжают работать локально.
- Новый релиз не мигрирует и не очищает хранилище проектов.
- Смена ключа и установка версии с другим applicationId этим механизмом не поддерживаются.
- Установка из Google Play — отдельный сценарий; этот механизм предназначен для
  самостоятельно распространяемой APK.

## Приёмочная проверка после подключения GitHub

1. Поставьте 0.1.2, создайте и сохраните тестовый чертёж, экспортируйте `.zamer`.
2. Опубликуйте 0.1.3 с versionCode 4 в выбранном репозитории.
3. Нажмите «Проверить» → «Скачать» → подтвердите установку Android.
4. Запустите приложение, проверьте новую версию в «Обновлениях» и сохранность чертежа.
5. В авиарежиме ручная проверка должна показать ошибку соединения; чертёж должен открываться.
6. Отмените скачивание/установку: текущая версия и проекты должны оставаться рабочими.
7. В отдельном тестовом репозитории замените sha256 на неверный: установка должна отмениться.
8. APK с другим ключом или пакетом не должен дойти до установки.

Локально проверена политика URL: 24 проверки, включая HTTP, чужой хост,
подмену домена, другой репозиторий, нестандартный порт, userinfo и localhost.
Полный цикл установки требует телефона и опубликованного релиза.

## Управление объектами — 0.1.5

Короткое касание с отпусканием активирует объект. Жест с движением по неактивному объекту перемещает экран; объект не активируется и не меняет геометрию. После активации следующий жест двигает объект. Тап по пустому месту снимает выделение. 49 тестов, проверка синтаксиса/кодировки, assembleRelease/lintRelease, apksigner/zipalign прошли. Проверка на физическом телефоне остаётся.


## Управление и размеры — 0.1.6

Пальцем после активации можно перемещать только мебель и текст. Стены, линии, круги, дуги, прямоугольники, размеры и выноски перемещаются командой «Переместить»; жест по ним двигает экран. Включение инструмента «Размер» показывает слой размеров. Исправлены границы отображения вынесенных и угловых размеров.

52 теста прошли. В браузере проверены создание размера по трём точкам, повторное открытие проекта и показ скрытого слоя. Сравнение экспортированных .zamer подтвердило: жест по выделенной стене меняет только вид, команда «Переместить» меняет координаты стены. Физический телефон пока не проверен.

## Конечные точки линий — 0.1.7

Исправлена регрессия 0.1.6: запрет переноса целой линии больше не блокирует отдельное редактирование её концов. После завершённого тапа по линии или стене можно выбрать конечную точку, подвести центральный курсор и подтвердить новую позицию касанием холста. Активная операция подтверждается и при касании поверх линии. Перенос всей линии остаётся командой «Переместить», обычный жест по её телу перемещает экран.

В браузере проверены оба конца линии, числовое изменение длины, подтверждение точки, отмена и прокрутка поверх выделенной линии. Сравнение экспортов .zamer подтвердило неизменность противоположной точки, восстановление исходной геометрии после отмены и отсутствие изменений координат при прокрутке. 52 теста, проверка кодировки, 24 проверки политики обновлений, assembleRelease/lintRelease, release-подпись и выравнивание APK прошли. Физический телефон не подключён, установка на нём остаётся для проверки.

Опубликована как Latest: https://github.com/temirlan2994/zamer-cad-releases/releases/tag/v0.1.7 . Анонимно проверены latest, update.json (versionCode 8) и скачивание APK; SHA-256 совпал с манифестом: `55b46e2d4c45654dde554f3aba7357b276220a487c6032f0be582c29114eb62c`.
