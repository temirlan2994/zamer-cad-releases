# Zamer CAD — подписанный офлайн APK

Версия **0.1.2**, versionCode **3**, пакет `com.zamercad.offline`.
Требуется **Android 10+** (minSdk 29, targetSdk 35). HTML, JavaScript, CSS и
символы встроены в APK. Режим `?apk=1` хранит проекты в WebView localStorage и
IndexedDB. Сервер и аккаунт не нужны. Интернет нужен только для проверки и загрузки обновлений. Чертежи работают офлайн.
Подробнее: [удалённые обновления](UPDATES.md).

## Сборка

Проверены Temurin JDK 17.0.19, Gradle Wrapper 8.11.1, AGP 8.9.1,
SDK Platform 35, Build Tools 35.0.0, platform-tools/adb.
SDK: `C:\Users\7\.cache\zamer-android\sdk` (настроен в игнорируемом local.properties).
Из корня проекта в PowerShell:

```powershell
Set-Location .\android-offline
.\gradlew.bat clean assembleRelease lintRelease --offline --console=plain
```

Чистая сборка без интернета проверена. На новом компьютере первый запуск
требует загрузки Gradle и зависимостей: уберите `--offline`.
Результат: `app\build\outputs\apk\release\app-release.apk`.
Копия для телефона: `..\dist\Zamer-CAD-0.1.2-release.apk`.
Размер, SHA-256 APK и отпечаток сертификата: `..\dist\release-info.txt`.

## Подпись и секреты

Существующий ключ сохранён: RSA-3072, alias `zamer`, сертификат до 05.12.2053.
Ключ и конфигурация перенесены из проекта/OneDrive в:

```text
C:\Users\7\.zamer-cad\signing\zamer-release.jks
C:\Users\7\.zamer-cad\signing\keystore.properties
```

NTFS-наследование отключено: доступ имеют текущий пользователь и SYSTEM.
Пароль хранилища не короче 20 символов; секреты не выводились в журнал.
Конфигурация содержит открытые пароли и защищена правами NTFS, не отдельным
шифрованием. Не передавайте эту папку вместе с APK.
Старые рабочие копии удалены; возможные копии в истории OneDrive этим не удаляются.

Gradle читает `%USERPROFILE%\.zamer-cad\signing\keystore.properties`.
Переопределение для другого компьютера:

```powershell
$env:ZAMER_SIGNING_PROPERTIES = 'D:\Private\Zamer\keystore.properties'
```

Формат конфигурации (заполнить локально; путь с прямыми слешами):

```properties
storeFile=D:/Private/Zamer/zamer-release.jks
storePassword=<секрет>
keyAlias=zamer
keyPassword=<секрет>
```

Release без конфигурации подписи завершается ошибкой — проверено.
Сделайте зашифрованную резервную копию обоих файлов на отдельном носителе и
проверьте восстановление. Автоматическая резервная копия не создавалась.
Для будущих обновлений сохраняйте этот ключ и applicationId, увеличивайте versionCode.
Без прежнего ключа нельзя обновить установленную версию.
[Документация Android](https://developer.android.com/studio/publish/app-signing).

## Установка через файл

1. Передайте только `dist\Zamer-CAD-0.1.2-release.apk` по USB в «Загрузки» телефона.
2. Откройте APK через «Файлы». Если Android запросит, разрешите установку из
   этого источника для файлового менеджера.
3. Нажмите «Установить» → «Открыть». Приложение называется «Замер CAD».
4. Отключите разрешение установки из этого источника после установки.

Если установлена debug-версия с другим сертификатом, обновление будет отклонено.
Экспортируйте нужные проекты в `.zamer`, затем удалите debug и установите release.
Удаление приложения или очистка данных стирает локальные проекты:
сначала экспортируйте резервные `.zamer` вне приложения.

## Установка через ADB

Включите режим разработчика и «Отладка по USB». Подключите и разблокируйте
телефон, подтвердите доверие компьютеру. Команды из корня проекта:

```powershell
$adb = 'C:\Users\7\.cache\zamer-android\sdk\platform-tools\adb.exe'
& $adb devices -l
# Ожидается устройство со статусом device, не unauthorized.
& $adb install -r '.\dist\Zamer-CAD-0.1.2-release.apk'
# Ожидается Success.
& $adb shell am start -n com.zamercad.offline/.MainActivity
& $adb shell dumpsys package com.zamercad.offline | Select-String 'versionCode|versionName'
# Ожидается versionCode=3, versionName=0.1.2.
```

При нескольких устройствах добавляйте `-s СЕРИЙНЫЙ_НОМЕР` сразу после `$adb`.
При сбое запуска получите журнал: `& $adb logcat -d -b crash`.

## Проверка на телефоне — ещё требуется

При сборке ADB не обнаружил устройств. Запуск на телефоне не выполнялся.

1. Включите авиарежим и выключите Wi-Fi. Запустите приложение: список проектов
   должен открыться без входа в аккаунт и без сервера.
2. Создайте «APK тест», начертите комнату/стены, задайте размеры, добавьте дверь
   и предмет из библиотеки. Проверьте касания, масштаб и панели инструментов.
3. Дождитесь сохранения. Вернитесь к списку и откройте проект повторно.
   Принудительно остановите приложение через настройки Android, запустите снова:
   название, геометрия и размеры должны сохраниться.
4. Экспортируйте `.zamer` и DXF. Проверьте непустые файлы в
   «Файлы → Загрузки → Zamer CAD». Откройте DXF в CAD-просмотрщике.
5. Импортируйте `.zamer` через список проектов и сравните геометрию и размеры.
   Отдельно проверьте отмену выбора файла без зависания интерфейса.
6. Перезагрузите телефон и повторно откройте проект в авиарежиме.
7. Повторите `adb install -r` той же release-APK: ожидается Success, проекты
   должны остаться. Не удаляйте приложение между установками.

- Чистая `assembleRelease lintRelease --offline`: успешно.
- `apksigner verify --verbose --print-certs`: успешно, подпись v2.
- `zipalign -c -P 16 -v 4`: успешно.
- `aapt dump badging/permissions`: версия 0.1.2 (3), minSdk 29, targetSdk 35,

  `android.overridePathCheck=true`; сборка успешна.
