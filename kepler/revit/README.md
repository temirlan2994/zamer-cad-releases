# Kepler Plan → Revit (надстройка)

Команда **«Импорт Kepler Plan»** строит в открытом проекте Revit настоящие
элементы из файла «Структурированный JSON» (Экспорт → JSON, схема
`kepler-export/2`).

> **Статус.** Сборки с API Revit 2025 и 2026 проверены на .NET 8: без ошибок и предупреждений. Запуск внутри настоящего Revit пока не проверен. Перед рабочим применением выполните приёмку ниже в тестовом документе. Контракт JSON дополнительно проверяется автоматически (`tests/revit-contract.test.mjs`).

Для IFC-совместимых программ (Revit тоже открывает IFC) есть экспорт IFC4 —
его можно открыть сразу, без надстройки.

## Сборка и установка

```bash
cd kepler/revit
dotnet build -c Release -p:RevitVersion=2025
# Для Revit 2026 соберите отдельную DLL:
dotnet build -c Release -p:RevitVersion=2026
```

Скопируйте `bin/Release/net8.0-windows/KeplerRevit.dll` и
`KeplerImport.addin` в `%AppData%\Autodesk\Revit\Addins\2025\`
(или 2026). В Revit: вкладка «Надстройки» → «Внешние инструменты» →
«Импорт Kepler Plan».

Справочные сборки Revit API берутся из NuGet (`Nice3point.Revit.Api.*`) и в
выходную папку не копируются.

## Что создаётся

| Kepler | Revit |
|---|---|
| Этаж (отметка, имя) | Уровень + план этажа (существующий уровень на той же отметке используется) |
| Стены (ось, толщина, несущая) | Базовые стены; типы «Kepler NNN мм» создаются по толщине |
| Свободные стены | Базовые стены |
| Двери, окна (ширина, высота, подоконник) | Экземпляры первого семейства дверей/окон проекта; тип «Kepler Ш×В» с нужным размером |
| Проём без двери | Прямоугольный вырез в стене |
| Помещения (имя, номер экспликации, высота) | Помещения по внутренней точке комнаты, верхний предел — высота потолка |
| Колонны | Первое семейство колонн проекта, с поворотом |
| Север дома | Угол истинного севера проекта |

Оси: Kepler — мм, Y вниз; Revit — внутренние единицы, Y вверх (координата
Y меняет знак, поворот по часовой становится поворотом против).

## Ограничения

- Двери и окна берутся из загруженных в проект семейств: загрузите нужные
  до импорта. Если у семейства нельзя поменять размер — ставится как есть
  (в итоговом окне будет замечание).
- Открывание и петли применяются, если семейство поддерживает отражение. Проверьте ориентацию после импорта.
- Перекрытия, крыши, лестницы, мебель и фасадные массы передаются дополнительной геометрией DirectShape; их нативная параметризация не сохраняется.
- Положение дома в координатах съёмки (общие координаты) не задаётся —
  только направление на север. Знак угла севера стоит проверить на первом
  проекте.

## Обновление и сохранность документа

Команда предлагает обновить ранее импортированные элементы или добавить отдельную копию. ExtensibleStorage хранит идентификаторы исходного проекта и объекта. Повторный импорт обновляет только помеченные элементы, пропускает неизменённые и удаляет отсутствующие в полном экспорте. Ручные элементы и обнаруженные чужие зависимости защищаются от удаления; замечание попадает в отчёт. Старый неполный JSON не удаляет ранее импортированную дополнительную геометрию.

После импорта сохраните JSON-отчёт и загрузите его в «Концепция → Передача» исходного проекта. Контрольная сумма должна совпадать с текущим состоянием. Загрузка отчёта фиксирует выполненный внешний запуск и его замечания; она не заменяет визуальную проверку результата.

## Приёмка в Revit

Проверяйте в отдельной копии тестового проекта с загруженными дверями и окнами:

1. Импортировать двухэтажный дом; сверить отметки, высоты/толщины стен, внутреннюю точку помещений, размеры и поворот колонн, север.
2. Проверить окна, двери, пустые проёмы и межэтажное остекление: вырезы верхних стен, подоконник, полную высоту рам и отражение дверей.
3. Сверить лестницы, площадки, кровлю, перекрытия, мебель и фасадные массы DirectShape с Kepler.
4. Повторить импорт без изменений: число элементов не растёт. Изменить размеры/отметку/поворот, в том числе вернуть поворот в ноль; повторить и сверить результат.
5. Добавить ручной элемент, удалить объект в Kepler, повторить импорт: чужие элементы сохраняются, удаление помеченных объектов отражено в отчёте.
6. Импортировать отдельную копию: исходный импорт не изменяется. Отменить транзакцию средствами Revit и проверить документ.
7. Сохранить отчёт импорта. Любые предупреждения о семействах и пропущенной геометрии разобрать до передачи документа.
