# Kepler Plan → Revit (надстройка)

Команда **«Импорт Kepler Plan»** строит в открытом проекте Revit настоящие
элементы из файла «Структурированный JSON» (Экспорт → JSON, схема
`kepler-export/2`).

> **Статус.** Код написан по документированному Revit API 2025, но в среде,
> где он создавался, его нельзя было собрать и запустить: нет .NET SDK и
> самого Revit. Перед использованием соберите его и проверьте на тестовом
> проекте. Договор полей JSON проверяется автоматически
> (`tests/revit-contract.test.mjs`).

Для IFC-совместимых программ (Revit тоже открывает IFC) есть экспорт IFC4 —
его можно открыть сразу, без надстройки.

## Сборка и установка

```bash
cd kepler/revit
dotnet build -c Release
```

Скопируйте `bin/Release/net8.0-windows/KeplerRevit.dll` и
`KeplerImport.addin` в `%AppData%\Autodesk\Revit\Addins\2025\`
(или 2026). В Revit: вкладка «Надстройки» → «Внешние инструменты» →
«Импорт Kepler Plan».

Справочные сборки Revit API берутся из NuGet (`Nice3point.Revit.Api.*`) и в
выходную папку не копируются.

## Что создаётся

| Kepler | Revit |
|---|---|
| Этаж (отметка, имя) | Уровень + план этажа (существующий уровень на той же отметке используется) |
| Стены (ось, толщина, несущая) | Базовые стены; типы «Kepler NNN мм» создаются по толщине |
| Свободные стены | Базовые стены |
| Двери, окна (ширина, высота, подоконник) | Экземпляры первого семейства дверей/окон проекта; тип «Kepler Ш×В» с нужным размером |
| Проём без двери | Не ставится (разрыв в стене) |
| Помещения (имя, номер экспликации, высота) | Помещения по центру комнаты, верхний предел — высота потолка |
| Колонны | Первое семейство колонн проекта, с поворотом |
| Север дома | Угол истинного севера проекта |

Оси: Kepler — мм, Y вниз; Revit — внутренние единицы, Y вверх (координата
Y меняет знак, поворот по часовой становится поворотом против).

## Ограничения

- Двери и окна берутся из загруженных в проект семейств: загрузите нужные
  до импорта. Если у семейства нельзя поменять размер — ставится как есть
  (в итоговом окне будет замечание).
- Сторона открывания дверей и петли не переносятся — поправьте «Отразить».
- Мебель не переносится: проще расставить семействами.
- Положение дома в координатах съёмки (общие координаты) не задаётся —
  только направление на север. Знак угла севера стоит проверить на первом
  проекте.
