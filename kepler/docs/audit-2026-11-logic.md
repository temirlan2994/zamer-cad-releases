# Kepler Plan: продуктовый и логический аудит (агент C: логика, модель, полнота)

Пути даны относительно `kepler/`. Пометка [проверено] — дефект воспроизведён скриптами на Node по ядру.

## Сводка
1. **Самое опасное.** Смена толщины общей стены делает её не общей [проверено]. `changeWallThickness` (`ui/plan-actions.js:628`) сдвигает соседа, а `findAdjacencies` признаёт общей только стену с зазором = `settings.partition` ±1 мм (`core/walls.js:83`). В зазоре 300 мм получаются две наружные стены по 250 мм, дверь между комнатами становится входной, комната — недостижимой. Внутреннюю несущую 380–510 мм построить нельзя.
2. **Окна и двери уезжают за перенесённой западной или северной стеной** [проверено]. Отступ проёма от `room.x/y`, `moveRectEdge` (`core/wall-edit.js:27`) и `applyResize` (`ui/snap.js:38`) его не компенсируют.
3. **Окно остаётся в стене, ставшей внутренней** [проверено]. `clampOpeningOffset` (`core/walls.js:615`) не проверяет вид проёма; окно засчитывается в норму света 1:8. Дверь на бывшей общей стене молча становится входом.
4. **Г-образные комнаты половина ядра считает по габариту.** Площадь 18,59 м² вместо 27, если сосед в вырезе [проверено] (`core/rooms.js:259-290`, `eatersOf`). `removeRoom` удаляет мебель соседа из выреза [проверено]. Окно на стене выреза роняет `normsReport` с `TypeError` [проверено]: `core/insolation.js:150` ждёт сторону 0–3, а получает `'notch-h'`; `ui/store.js:63` глотает ошибку, панель норм пропадает. IFC выгружает прямоугольником; Revit ставит помещение в среднюю вершину полигона.
5. **ТЭП.** Застройка без террас (`core/tep.js:3`). Одна методика общей площади: нет СП 55 / кадастр / РК, коэффициентов 0,3 и 0,5. «Лестница» засчитывается на каждом этаже [проверено]. В каталоге нет детской, котельной, кладовой.
6. **Нормы.** 4 проверки СП 55 + инсоляция. Нет туалета, мансарды, мокрых зон над жилыми, ширины/уклона лестницы. Профиля РК нет, хотя участок по умолчанию в Алматы. Красная линия рисуется, но не проверяется (`core/site.js:192`). Отступ 1,5 м по умолчанию — такого значения нет в нормах.
7. **Этажи.** Смена высоты этажа не сдвигает отметки верхних. `addLevel` копирует полный марш вместо проёма с ограждением. `item.floorHeight` у лестницы устаревает. Нет цоколя, подвала, мансарды; перекрытие зашито 300 мм.
8. **Сохранение.** Подложка base64 внутри проекта → в каждом снимке истории (на каждый pointerdown) и в localStorage. Переполнение localStorage гасится молча. Нет сохранения на `pagehide`. В облако только по кнопке; `saveVersion` без проверки версии — две вкладки теряют версии друг друга.
9. **Экспорт.** IFC — «коробка без полов»: нет перекрытий, кровли, лестниц, ограждений, Pset. DXF — 3 слоя, проёмы на слое стен, подписи «m2». PDF — растр 150 dpi.
10. **Чего нет из главного:** кровля, фасады и разрез, цоколь с посадкой на рельеф, несущие стены как класс, оси, выбор методики площадей и профиль норм, PDF-альбом, смета.
11. **Техдолг.** `render.js` 2284 строки, `ui/input.js` 1098. Дубли `rectUnionArea`/`rectsUnionArea`, две модели формы (`notch` и `outline`), `MIN_PASSAGE` 700 vs 600. Полный `normsReport` и стены всех этажей на каждое изменение.
12. **Не покрыто тестами:** `removeRoom`, `changeWallThickness`, Г-формы с нормами и соседями, история и автосохранение.

## 2. Логические дефекты

### 2.1 Общие стены (критично)
- [проверено] `changeWallThickness` (`ui/plan-actions.js:628-648`) сдвигает соседнюю комнату на дельту толщины, `findAdjacencies` требует зазор, ровно равный перегородке (`walls.js:83`).
- При 100 → 300 мм: общая стена исчезает; у каждой комнаты своя наружная 250 мм (500 мм стен в зазоре 300); `doorLink` (`walls.js:524`) возвращает `'outside'`, комната недостижима.
- Панель (`props.js:268`, «50–450 мм») обещает поведение, которого нет. Тип «Несущая» (`props.js:284`) меняет только метку.
- Исправление: толщину хранить в `wallOverrides[s|a|b]`, зазор признавать, если он равен этой толщине. Нужно 3 класса толщин: наружная, внутренняя несущая, перегородка.

### 2.2 Г-формы считаются по габариту
- **Площадь** [проверено]. `roomNetAreaM2` (`rooms.js:259-290`) вычитает по `roomRect` (`:271, :279, :286`); `eatersOf` (`:233`) тоже по габариту.
- **Удаление** [проверено]. `removeRoom` (`model.js:203-216`) удаляет мебель по габариту.
- **Окно на стене выреза** [проверено]. `windowsOf` берёт `NORMALS[o.side]` (`insolation.js:119, 150`), `side` строковый (`room-shape.js:345`) → `TypeError`; `refreshNorms` (`store.js:63-69`) пишет `norms = null`.
- **Нормы ширины** (`norms.js:170`) — `min(w, h)` габарита. **Автомебель** (`furnish.js:45, 114`), **инсоляция** (`insolation.js:101`) — по габариту. **IFC** `IfcSpace` прямоугольник (`ifc.js:216`). **DXF** подпись по габариту (`export.js:294-315`). **Revit** `NewRoom` в средней вершине полигона (`revit/src/KeplerImporter.cs:222-225`). **Генератор** `w*h` (`generator.js:29`).
- Нужна одна модель `outline`.

### 2.3 Проёмы
- [проверено] Отступ от `room.x/y` (`model.js:114`); `moveRectEdge` (`wall-edit.js:27-37`), `applyResize` (`snap.js:38`), `finalizeRoomOutline` (`room-shape.js:57`) не компенсируют.
- [проверено] После стыковки окно остаётся на общей стене: `clampOpeningOffset` (`walls.js:615`) не проверяет вид.
- После удаления соседа дверь молча становится входом (`walls.js:524-533`). `reconcileOpenings` (`plan-actions.js:24`) сообщает только число удалённых.
- Понятия «главный вход» нет; без входа источник связности — первая комната (`rooms.js:333`). Вход на верхнем этаже — только `stairs-room` (`rooms.js:326`); лестница-предмет не считается.

### 2.4 Перемещение, копирование, удаление
- `moveRoomBy` (`rooms.js:179`) везёт мебель из зоны перекрытия с соседом. `pasteRoom` (`plan-actions.js:382`) тихо перекрывает соседей. Вставить на другой этаж «на то же место» нельзя. Комнаты нельзя зеркалить/поворачивать (`plan-actions.js:259, 544`). В `wallOverrides` остаются ключи удалённых комнат.

### 2.5 Этажи и лестницы
- Высота этажа (`props.js:121`) не сдвигает отметки верхних. `addLevel` (`levels.js:64-97`) копирует полный марш. `item.floorHeight` кэшируется (`stairs.js:29-41`, `levels.js:85`). Проверяются только подступенок, проступь, 2h+b (`stairs.js:59-62`): нет ширины марша ≥0,9 м, уклона, высоты прохода, ограждения. `DEFAULT_SLAB = 300` (`model.js:26`). Нет цоколя, подвала, мансарды, вставки, дублирования этажа.

### 2.6 Площади и ТЭП
- [проверено] Застройка без террас (`tep.js:3`, `rooms.js:468`). Консоли верхних этажей не попадают (`tep.js:21`).
- Общая площадь = Σ чистых (`schedule.js:87-93`); нет методик: СП 55 (лоджии ×0,5, балконы/террасы ×0,3, веранды ×1), кадастр (по внутреннему контуру наружных стен, включая перегородки), РК.
- Жилая (`schedule.js:62`): нет детской и гостевой; гараж и котельная без признака «нежилое». [проверено] «Лестница» на каждом этаже. Объём без кровли (`tep.js:28`). Нет теста `tepReport`.

### 2.7 Нормы
- Есть (`norms.js:145-196`): площади 12/8/6, ширины 1,7/1,4/0,85/1,5, свет 1:8, высота 2,5; инсоляция, проходы.
- Нет: туалет 0,8×1,2; ширина спальни 2,25; мансардный свет 1:10; 2,7 м в холодных районах; санузел над жилой; котельная. Нормы РК не заведены (`site.js:15` — Алматы). Инсоляция по СанПиН 1.2.3685-21 верна; для ИЖС — рекомендация. Свет по `width × height`. Кухня-гостиная со скрытой стеной проверяется как две комнаты.

### 2.8 Участок и рельеф
- `checkRectBuildable` (`site.js:192-222`): только равномерный отступ; красная линия не учитывается. Отступ 3 м против `DEFAULT_SETBACK_BOUNDARY = 1500` (`site.js:8`). Противопожарный разрыв 6–15 м, а не 6. Только углы комнат; нарушение — предупреждение.
- Тени используют `site.buildingHeight` (`props-site.js:74`, `render.js:759`), инсоляция — этажи: два источника правды.
- Рельеф: обрезка 5000 точек без сообщения (`terrain.js:49`); линейный `locate` (`:254`); подпись на каждом кадре (`:231`, `ui/terrain-render.js:24`); на ТЭП и цоколь не влияет.

### 2.9 Сохранение и история
- Подложка base64 в `site.underlay.src` (`underlay.js:207`): `snapshot()` на каждый pointerdown (`input.js:358-584`), до 40 копий; localStorage (`store.js:86-93`) молча перестаёт сохранять.
- Нет `pagehide`/`beforeunload`; облако по кнопке (`projects.js:118`). Один ключ автосохранения на все вкладки.
- `saveVersion` (`storage.js:139-190`) без проверки версии; `deadBlobs` может удалить картинку другой вкладки; `revision` не используется.
- Варианты — полные копии дома внутри проекта.
- Новые поля (`notch`, `outline`, `terrain`, `comp`, `hidden`, `ceiling`, `stairShape`, `takesArea`) без поднятия схемы. `normalizeProject` (`model.js:165`) не проверяет комнаты.

### 2.10 Экспорт
- **DXF** (`export.js:214-359`): слои `walls`/`furniture`/`dimensions`, проёмы на слое стен; нет полилиний помещений и штриховки; «m2»; этажи в ряд без базовой точки.
- **IFC**: нет IfcSlab, IfcRoof, IfcStair, IfcRailing, Pset_WallCommon (IsExternal, LoadBearing), Qto.
- **PDF** — растр.

## 3. Чего не хватает (зачем → сложность → что затронет)
- Кровля: скатная, вальмовая, плоская → 2–4 д → `mesh3d`, `ifc`, `tep`, новый `core/roof.js`.
- Фасады → 2–3 д → `sheet.js`. Разрез → 3 д, нужен слой перекрытий.
- Цоколь и посадка на рельеф → 1–2 д (`terrain.floorZ` есть).
- Несущие стены и 3 класса толщин → 1–2 д после 2.1. Оси А-Б / 1-2 → 1 д.
- Окна по ритму фасада, витражи, эркер → 2 д. Ворота гаража, связь въезд → гараж → 1 д.
- Мокрые зоны по этажам → 0,5–1 д. Зонирование день/ночь → 1 д. Ориентация по сторонам света → 0,5 д.
- Смета по ТЭП → 1 д. Выбор методики площадей → 1 д. Профиль норм РК/РФ → 1–2 д.
- PDF-альбом → 2 д. Сравнение вариантов → 0,5–1 д. Типовые узлы → 2 д.
- Импорт плана из DXF → 3–5 д. Совместная работа → 2–3 д. Мансарда → 2–3 д после кровли.
- Каталог помещений → 0,5 д. Планшет → 1–2 д. Мебель в 3D и блоки DXF → 2 д.

## 4. Что отточить
1. Общая стена через override (2.1).
2. Одна модель `outline`; все расчёты через `roomRects`/`roomContainsPoint` (2.2).
3. Проёмы: компенсация отступа; окна только на наружных; ложный вход (2.3).
4. Этажи: каскад отметок, «этаж ниже / цоколь / дублировать»; на верхнем этаже — проём лестницы.
5. ТЭП: застройка с террасами, методики, коэффициенты, признак нежилого, «м²» в DXF.
6. Нормы: профиль РК/РФ, недостающие проверки, кухня-гостиная как одно пространство.
7. Участок: красная линия, отступ 3 м, проверка рёбер дома, высота для теней из этажей.
8. Генератор: многоэтажный, сохраняет формы.
9. Листы: 300 dpi или вектор, лист ТЭП, 3D, фасады.
10. IFC: перекрытия, лестницы, ограждения, Pset, полигональные IfcSpace, `check-ifc.py`.
11. Сохранение: подложка в IndexedDB blob по хешу; `pagehide`; тост при квоте; автоверсия по таймеру; оптимистическая блокировка.
12. Константы: `MIN_PASSAGE` 700/600; `|| 100` (`plan-actions.js:384`); README устарел («схема 3»).

## 5. Технический долг
- Размеры: `render.js` 2284, `input.js` 1098, `plan-actions.js` 658, `walls.js` 636, `props.js` 532, `kitchen.js` 511, `mesh3d.js` 505, `export.js` 499, `furnish.js` 481; всего ~18 000. `render.js` разбить на `render/plan`, `render/site`, `render/furniture-symbols`, `render/dims`; в `input.js` ~20 веток `drag.kind` → таблица.
- Дублирование: `rectUnionArea`/`rectsUnionArea`; `merge` в `computeRoomEdges` и `unionEdges`; «внутри комнаты» по габариту в 3 местах; две модели формы.
- Производительность: `deriveWalls` ×2 на pointermove; `findAdjacencies` O(n²·рёбра²); полный `normsReport` на каждое изменение; холст целиком; снимок с base64 на pointerdown. Выход: кэш стен по ревизии, пересчёт норм в idle.
- Хрупкое: `side` число или строка; геттеры `project.rooms` теряются при `{...project}`; `refreshNorms` глотает ошибки; `revit/` не в CI.
- Тесты: не покрыты `removeRoom`, `changeWallThickness`, `buildSheetsPdf`, Г-формы с нормами, каскад этажей, `ui/store.js`, параллельный `saveVersion`. Нужны инварианты: проёмы не сдвигаются при переносе стены; Σ площадей ≤ контур; окна только на наружных.
