# Завершение продукта Kepler

Запрос: реализовать восемь направлений из продуктового разбора. Ранее подготовленное выравнивание панели 3D сохраняется; `design-qa.md` не относится к этой работе.

## Приёмка

- [x] Связи модели: транзакционная правка уровней с переносом связанных отметок; диагностика разорванных ссылок; Undo/Redo; согласованность 3D и экспорта.
- [x] Варианты: создание, именование, копирование, переключение, удаление и сравнение домов на общем участке и по общему заданию; сохранение и миграции.
- [x] Бюджет: измеримые объёмы, пользовательские расценки, регион/валюта/дата/источник, диапазон и неполнота, лимит бюджета, сравнение и экспорт.
- [x] Согласование: неизменяемый снимок, клиентский просмотр, замечания с местом, ответ и фиксация решения по конкретному снимку; отзыв/истечение ссылки; импорт офлайн-ответа.
- [x] Передача: проверка модели перед экспортом, комплект с манифестом и устойчивыми идентификаторами, проверка импортёра и отчёт; реальный Revit выделен как внешняя приёмка.
- [x] Реализуемость: выбранная конструктивная система, материалы/слои, проверяемые геометрические противоречия, явно неизвестные инженерные данные.
- [x] Региональные правила: явный профиль, источник/редакция/область, пользовательские параметры, неизвестное не становится соответствием; подключение подтверждённых профилей.
- [x] Маршрут: видимый следующий шаг и состояния готовности, ссылки на существующие этапы, итоговый комплект.

## Проверки

Для каждой функции — чистые проверки ядра и браузерные сценарии реальных действий. Итог: lint, unit, профильные e2e, старые файлы, desktop/mobile, перезапуск, Undo/Redo, экспорт. Не добавлять тесты, которые лишь повторяют разметку.

## Внешняя приёмка

- Установленный Autodesk Revit и лицензированные API нужны для реального запуска импортёра. Код и контрактные проверки не подменяют эту приёмку.
- Применимость юридических/строительных норм подтверждается источниками и специалистом; встроенный профиль с неподтверждённой применимостью остаётся предварительным.
- Облачным ссылкам нужны развёрнутые правила Firestore. Изменять действующие права данных автоматически без проверки миграции нельзя; проверить локальными сценариями и документировать развёртывание.

Не объявлять весь продукт или внешние интеграции идеально проверенными, пока соответствующая приёмка не выполнена.

- Повреждённые необязательные метаданные концепции очищаются при чтении; они не ломают проект и не создают ложное согласование.
- Desktop/mobile: варианты, изменение геометрии, бюджет, неизвестный регион, снимок, согласование, сброс после изменения, Undo, перезагрузка и отсутствие фонового редактирования под диалогом.
- Клиентский HTML: автономный просмотр после отключения сети, выбор точки прогулки, WASD и возврат к форме, защита встраиваемого JSON от исполнения, отметка места, загрузка ответа в журнал.

- Облачный протокол отдельно проверен на UTF-8-частях, повреждении данных, обрыве публикации, истечении и отзыве.
- Revit 2025 и 2026: обе сборки .NET 8 завершены без ошибок и предупреждений; в CI добавлены матричные сборки и установочные артефакты.
