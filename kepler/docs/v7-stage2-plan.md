# Этап 2: подключение ядра v7 к приложению — план срезов

Проект ядра — `docs/architecture-v7.md`. Здесь — как оно входит в
приложение, по вертикальным срезам: после каждого приложение работает,
связанные unit/e2e зелёные, lint чист, локальный коммит.

## Почему мост, а не сразу `state.project` = v7

Модель v6 (`state.project.rooms/openings/walls`) читают ~25 тыс. строк:
`render.js` (2,9 тыс.), `ui/input.js` (1,5 тыс.), свойства, ТЭП, нормы,
расстановка мебели, 3D, IFC/DXF/PDF, ландшафт, варианты. Перевести всё
разом — неделя работы с приложением, которое между делом не запускается.
Поэтому этап 2 идёт через **мост v6↔v7**:

- истина съедания — **номинальные формы** (в v6-представлении это
  `room.eatBase.base`, у несъеденной — сама форма) и **порядок массива
  `rooms`** (= z v7: кто позже — тот выше);
- видимая форма съеденной комнаты — **результат `core/v7/carve.js`**,
  пересчитывается С НУЛЯ при каждой правке (`core/v7/eat-bridge.js`,
  `reconcileEats`), а не «съедается и запоминается» в конце жеста. Старые
  потребители видят обычные состыкованные комнаты, как раньше;
- файл — `kepler-plan/7` (`fromV6`), открытие — `fromAny` → v7 → `toV6`
  (срез 2);
- дальше срезы переводят потребителей на `derive` по одному; когда все
  перейдут — мост и v6-форма уходят (срез 6).

Так жалобы (а)–(в) закрываются в первом же срезе: результат зависит только
от номиналов и порядка, а не от истории жестов.

## Срезы

1. **Съедание на v7 carve, путь-независимо** (сделано, см. ниже):
   `core/v7/eat-bridge.js` — `reconcileEats(project, {touched})`:
   номиналы восстанавливаются (сдвинутая съеденная — номинал сдвигается
   вместе с ней), «тронутые» жестом поднимаются наверх (если с кем-то
   пересекаются), видимые формы и «сироты»-проёмы — из `carveLevel`.
   Вызов — в `mutate` (любая правка), в конце жестов (`eatOverlapsAfter`),
   при удалении. `restoreEaten`/`eatOverlaps` больше не вызываются из UI.
   Пунктир номинальной формы у выделенной съеденной комнаты.
2. **Файл kepler-plan/7** (сделано, `core/v7/file.js`): `serializeProject` пишет v7 (`fileV7`: номиналы на копии + `fromV6`, неизвестные ключи проекта/этажа — как есть),
   `deserializeProject` понимает v7 (`toV6`: блок → комната, хост на ребре →
   сторона/отступ, `pairs` → `wallOverrides`, поворот 90° — в контур).
   Проверка: круг v6 → v7 → v6 на всех фикстурах без потерь. Автосохранение,
   «Проекты», облако — через те же функции. Экспорт `kepler-export/2` —
   как был (v6-форма внутри), этап 3.
3. **Жесты блоков на v7-операциях**: перенос/растяжение — на номинале
   (ручки по номиналу, видимая — заливкой), съедание на каждом кадре (кеш
   derive), магнит `magnetSnap` (300 мм, кнопка в «Привязках»), поворот
   0/90/180/270, вершины Г-формы, дублирование, шаблоны.
4. **Стены и проёмы**: инструмент «Стена» под любым углом, проём на ребре
   блока (`host {blockId, edge, offset}`), деление стены
   (`ui/split-input.js`), петля стен → помещение (семя), «Разобрать на стены»
   (`v7/explode.js`).
5. **Свойства, ТЭП, замечания, нормы, мебель** — из `derive.rooms/issues`
   (`core/issues.js`, `norms.js`, `tep.js`, `schedule.js`).
6. **Удаление старых путей**: `eatBase`/`restoreEaten`/`eatOverlaps`,
   `bound-rooms.js`, `walls-v2.js`/`ortho-grid.js`, заплатки v1.

Этап 3 (не здесь): `render.js` по `outline`, 3D/IFC/DXF/PDF из `derive`.
До него 3D и экспорт читают v6-форму, которую держит мост.

## Решения пользователя (приняты)

kepler-plan/7 при сохранении; зазор 100–450 — одна толстая стена; ближе
перегородки — отодвигать до точного зазора; терраса — минус стены дома;
магнит включён, 300 мм; поворот 0/90/180/270; съедание на лету, номинал
пунктиром у выделенного блока.

## Отступления (почему)

- **Порядок z = порядок массива `rooms`.** У v6 он уже значил «кто выше»
  (`roomOverlaps`, `bringRoomToTop`). Тронутая комната уходит в конец,
  только если пересекается с другой (с зазором перегородки): иначе порядок
  не влияет на результат, а лишняя перестановка ломала бы ссылки по индексу.
- **Вложенные помещения** в мосту не вырезаются из родителя (в v6 родитель
  целый, вложенное «отнимает» площадь отдельно); проверка `children` — как
  в v6 (`nestedOuterRect` внутри остатка).
- **Помещения по петлям стен (`bound`)** в съедании моста не участвуют:
  их форма следует за стенами (`bound-rooms.js`); на v7 это семена (срез 4).
- **Растянутая/правленная руками съеденная комната** (не чистый сдвиг):
  до среза 3 ручки стоят на видимой форме, поэтому новая видимая форма
  становится номиналом. В срезе 3 ручки переходят на номинал.
