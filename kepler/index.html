Управление

Мышь

  • ЛКМ — выбрать; по пустому месту — рамка
  • Тянуть комнату, мебель, проём, ручки углов
  • ПКМ / колесо нажато / пробел — панорама
  • Пробел при установке — повернуть предмет; у двери — петли и открывание
  • Колесо — масштаб
  • Shift + клик — добавить к выделению

Клавиши

  • Ctrl+Z / Ctrl+Shift+Z — отмена / повтор
  • Ctrl+C / Ctrl+V — копировать / вставить объект
  • Ctrl+D — дублировать, R — повернуть, M — зеркально
  • Del — удалить выбранное
  • Стрелки — сдвиг на 50 мм (Shift — 500)
  • PgUp / PgDn — этаж выше / ниже
  • Enter — закончить ломаную, Esc — отмена
  • Черчение линий: F8 — орто, Ctrl — орто временно, Shift — без привязок; число + Enter — точка на этой длине, Tab — угол
  • ? или F1 — эта справка

Пальцы (телефон, планшет)

  • Тап — выбрать, поставить выбранное
  • Один палец по пустому месту — двигать план
  • Два пальца — масштаб и сдвиг
  • Панели — кнопками внизу экрана

Режимы и виды

  • План — комнаты прямо по осям дома
  • Участок — север вверх, граница, соседи, солнце
  • Выровнять — дом вдоль линии участка (2 точки)
  • 3D — объём дома: тянуть — вращать
