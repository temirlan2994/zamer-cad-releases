# Kepler Plan — конструктор архитектурных концепций

Редактор для максимально быстрой сборки концепции частного дома: план
собирается из готовых блоков-помещений (как LEGO), а не чертится по стенам.
Ранняя концепция → утверждение → экспорт в Autodesk Revit для
профессионального проектирования.

Построен на основе **Zamer CAD**: чистый JavaScript + canvas, без фреймворков
и сборки (ES-модули прямо в браузере). Модули `core/zamer/` взяты из Zamer CAD.

## Запуск и проверки

```bash
cd kepler
npm ci                 # ESLint и Playwright — только для разработки
npm run serve          # http://127.0.0.1:8080/
npm run check          # линтер + юнит-тесты ядра + e2e в Chromium
npm run build:artifact # страница для claude.ai из index.html (dist/artifact)
```

Отладочный API для автотестов (`window.__kepler`) включается только с
`?debug` в адресе. CI (GitHub Actions, `.github/workflows/kepler.yml`)
гоняет `lint`, `test` и `test:e2e` на каждый PR.

## Что умеет (MVP)

- **Блочная система**: 14 типов помещений в библиотеке; клик — размещение.
  Комнаты стыкуются с привязкой, зазор автоматически равен толщине стены.
- **Единые общие стены**: стена между двумя комнатами — один объект;
  изменение её толщины сдвигает соседнюю комнату, тип (несущая/перегородка)
  задаётся в свойствах.
- **Вложенные помещения**: санузел или гардеробную можно разместить внутри
  комнаты — площадь родителя пересчитывается, мебель перестраивается.
- **Автоматическая меблировка**: у каждой комнаты набор мебели с галочками.
  Расстановка — детерминированный алгоритм: спинкой к стене, зоны доступа,
  зоны открывания дверей, окна (высокое не ставится на окно), проверка
  прохода от двери BFS-ом по сетке 100 мм. Если предмет не помещается —
  объясняется причина. Перемещённый вручную предмет закрепляется и при
  перестройке не трогается.
- **Двери и окна**: размещаются кликом по стене, двигаются вдоль неё,
  дверь — открывание внутрь/наружу, петли слева/справа. Окна — только на
  наружных стенах.
- **Анализ связности**: граф «двери соединяют помещения»; программа
  предупреждает о недостижимых комнатах и предлагает, где добавить дверь.
  Коридоры никогда не строятся автоматически — только по решению пользователя.
- **Участок**: топосъёмка (PDF/JPG/PNG/DXF), граница, красная линия, зона
  застройки с отступами, дороги, въезд, соседние дома с буфером 6 м, север,
  солнце и тени на дату и время.
- **Поворот дома**: «Выровнять» по двум точкам ставит оси дома вдоль линии
  участка (дом поворачивается на месте). Вид «План» идёт по осям дома —
  комнаты всегда прямые; «Участок» — север вверх.
- **Undo/Redo**, автосохранение в localStorage, открытие/сохранение файла
  `.kepler.json` (старые версии формата открываются через миграции).
- **Экспорт**:
  - структурированный JSON (`kepler-export/2`) — помещения, стены, проёмы,
    мебель, связи, участок и система координат дома — вход для плагина Revit;
  - DXF плана (R12 ASCII) в осях дома, включая профиль слоёв `ZAMER_*`;
  - DXF генплана в координатах съёмки: дом повёрнут, как стоит на участке,
    плюс слои участка — ложится поверх исходной топосъёмки.

## Архитектура

```
kepler/
  index.html          оболочка (три панели); из неё же собирается артефакт
  styles.css          палитра семейства Zamer CAD, светлая/тёмная темы
  app.js              точка входа: обработчики событий и запуск
  render.js           отрисовка плана, участка и условные обозначения мебели
  ui/                 интерфейс по модулям: state, store (история,
                      автосохранение), view, modes, input, keyboard, hit,
                      tools, plan-actions, site-actions, underlay, props,
                      library, files, toolbar и др.
  core/               ядро без DOM (тестируется в Node)
    model.js          модель проекта и сериализация
    migrate.js        версии формата kepler-plan/N и миграции между ними
    building.js       система координат дома (поворот относительно участка)
    catalog.js        типы помещений, мебель и правила расстановки
    walls.js          производный граф стен: общие стены, проёмы, символ двери
    rooms.js          размещение, привязка, вложение, площади, связность
    furnish.js        авторасстановка мебели (алгоритм + причины отказов)
    site.js           участок: зона застройки, соседи, солнце и тени
    dxf.js            разбор DXF-топосъёмки в подложку
    export.js         JSON для Revit, DXF плана и генплана
    zamer/            модули Zamer CAD: geometry.js, dxf.js, blocks.js
  scripts/            serve.mjs (сервер), build-artifact.mjs (сборка страницы)
  tests/              юнит-тесты ядра, e2e (Playwright), фикстуры форматов
```

Принципы: ядро — чистые модули без DOM; все размеры в миллиметрах, ось Y
вниз; стены не хранятся, а выводятся из прямоугольников комнат при каждом
изменении — поэтому они всегда согласованы.

## Системы координат

Комнаты, стены, проёмы и мебель хранятся в **осях дома** (прямоугольники без
поворотов — вся логика плана простая). Участок, соседи, дороги и топосъёмка —
в **координатах съёмки**. Связь — `project.building`:

```
world = origin + R(rotation) · local     (Y вниз, угол — по часовой)
```

Вид «План» = вид «Участка», повёрнутый и сдвинутый на поворот дома, поэтому
отрисовка и попадание курсора работают через один производный вид.

## Формат файла

`.kepler.json` со схемой `kepler-plan/N` (сейчас 3). Формат меняется только
вместе с миграцией в `core/migrate.js`; старые файлы и автосохранения
открываются цепочкой миграций, на каждую прошлую версию в `tests/fixtures`
лежит настоящий файл.

## Формат стен

Комната хранит внутренний прямоугольник. Стыковка двух комнат с зазором
50–450 мм рождает **общую стену** (`s|idA|idB`) толщиной в этот зазор.
Остальные участки сторон — собственные стены (`e|roomId|side`), наружные по
умолчанию 250 мм, перегородки вложенных комнат — 100 мм. Переопределения
толщины и типа хранятся в `project.wallOverrides` по этим ключам.

## Дорожная карта

1. **Плагин Revit (C#)** — чтение `kepler-export/2`, создание стен, проёмов,
   помещений и семейств мебели как настоящих BIM-элементов.
2. Помещения произвольной формы (полигоны), несколько этажей, лестницы
   со связью этажей.
3. Предложение коридоров по анализу связности (с подтверждением).
4. Мобильная версия на базе оболочки Zamer CAD (WebView, управление
   пальцами) и объединение с исходным проектом Zamer CAD.

## Связь с Zamer CAD

Код в `core/zamer/` извлечён из приложения Zamer CAD (владелец — автор
репозитория): `buildDxf`/`buildRevitDxf`, геометрические примитивы, габариты
блоков. Единственное расширение — `buildDxf(…, { extraLayers })` для слоёв
генплана. SVG-символы мебели Zamer CAD
(MIT, FloorPlanSVGSymbols) в Kepler не нужны — обозначения рисуются кодом.
